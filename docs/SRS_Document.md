# Software Requirements Specification

## Project Name

Smart Food Delivery System

## Objective

Build a Zomato-like food delivery platform that supports restaurant discovery, menu browsing, cart checkout, order tracking, restaurant management, delivery assignment, and admin monitoring.

## Users

- Customer
- Restaurant owner
- Delivery partner
- Admin

## Functional Requirements

- Users can register and login.
- Users can search restaurants by location, cuisine, rating, and price.
- Users can view restaurant menus.
- Users can add food items to cart.
- Users can place orders.
- Users can track order status.
- Restaurants can manage menu items.
- Restaurants can accept and update orders.
- Delivery partners can accept deliveries and update delivery status.
- Admin can monitor users, restaurants, orders, payments, and reports.

## Non-Functional Requirements

- The system should use role-based access control.
- The backend should expose REST APIs.
- The database should store normalized transactional data.
- The frontend should be responsive.
- The system should be maintainable and modular.

## Future Scope

- Payment gateway integration
- Google Maps tracking
- Push notifications
- AI recommendations
- Voice ordering
