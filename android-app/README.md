# Android App Structure

This folder is reserved for the Android Java version of the Smart Food Delivery System.

Suggested packages:

```text
android-app/
├── java/com/smartfood/
│   ├── activities/
│   ├── adapters/
│   ├── models/
│   ├── api/
│   ├── utils/
│   └── fragments/
├── res/
│   ├── layout/
│   ├── drawable/
│   └── values/
└── AndroidManifest.xml
```
